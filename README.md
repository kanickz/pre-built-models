# Pre-Built Models

This project demonstrates the implementation and use of pre-built machine learning models.

## Technologies Used
- Python
- NumPy
- Matplotlib

## Project Description
This project explores pre-built machine learning models and demonstrates how they can be used for prediction and data analysis.

## File
- `pre_built_models.ipynb` - Jupyter Notebook containing the complete project.

## How to Run
1. Download or clone this repository.
2. Open `pre_built_models.ipynb` in Jupyter Notebook or Google Colab.
3. Run the cells sequentially.
